# Установка

## 1. Что в релизе

Два файла для платы, оба в каталоге `picard/`: прошивка и банк
инструментов. Это не две разные прошивки: `bank.uf2` - инструменты для
MIDI, данные для той же прошивки.

**Прошивка одна на все машины.** Дисковые и звуковые устройства, в том
числе Z-Controller, включаются настройками ([config.md](config.md)),
отдельных прошивок для них нет.

| Файл | Размер | Когда нужен |
|---|---|---|
| `soundsinth.uf2` | ~1.2 МБ | при каждом обновлении |
| `bank.uf2` | ~30 МБ | один раз при первой установке |

Банк лежит во флеше выше первого мегабайта, а прошивка туда не достаёт:
заливка прошивки банк не трогает. Поэтому обновление - это один короткий
файл, а тридцать мегабайт пишутся только когда меняется сам банк.
Настройки и свои ПЗУ, записанные в плату, обновление прошивки тоже не
стирает.

Остальное в релизе для Спектрума и для карты:

| Файл | Что это |
|---|---|
| `ugly.$c`, `ugly.sna` | плеер TR-DOS: файл Hobeta и снимок 128К |
| `UMPLAYER.WMF` | плагин Wild Commander для TS-Config |
| `banks/` | банки инструментов для карты и их лицензии |
| `example/` | готовые файлы настроек под три машины |

## 2. Что заливать

**Обновление** - только прошивка, один файл. Банк остаётся на месте.

**Первая установка** - два файла, по очереди:

1. прошивка `soundsinth.uf2`;
2. затем `bank.uf2`.

Каждый файл заливается отдельно: после первого плата перезагружается
сама, и для второго её надо снова ввести в режим загрузки.

Банк можно залить и позже. Без него не работает **живой MIDI** и `.mid`,
присланный плеером General Sound: оба берут сэмплы только из флеша.
Файлы `.mid` с плеера на Спектруме играют и без него, если на карте лежит
банк - `midi.ssb` в её корне.

## 3. Залить на плату

**Кнопкой BOOTSEL** - если под рукой нет программатора:

1. Отключить питание платы.
2. Зажать BOOTSEL и подать питание.
3. Плата появится съёмным диском - скопировать на него `.uf2`.
4. Плата перезагрузится сама.

Для второго файла повторить с первого шага.

**По SWD** - если есть программатор CMSIS-DAP, это быстрее и без
манипуляций с кнопкой и питанием. Тем, кто собирает из исходников,
годятся готовые скрипты ([build.md](build.md)):

```
scripts\flash_zc.cmd            собрать и залить прошивку
scripts\flash_bank.cmd          залить банк инструментов
scripts\flash_zc.cmd bootsel    через BOOTSEL вместо программатора
```

## 4. Звук

Настраивать нечего: прошивка отдаёт 44100 Гц стерео по I2S на ЦАП платы -
GPIO 44 данные, 45 BCK, 46 WS. Куда идёт сигнал дальше, определяет схема
платы, а не прошивка; разъём ищите в её собственном описании.

## 5. Переключатель ZC/DIVMMC

На многих платах есть переключатель ZC/DIVMMC, на других на его месте
перемычка. В этой прошивке он ничего не переключает: дисковая система и
Z-Controller выбираются настройками. Переключатель служит входом в
конфигуратор: в положении, где он замкнут на землю, каждая загрузка
попадает в экран настроек. Для обычной работы держите его в другом
положении.

Про DivMMC - [divmmc.md](divmmc.md), про настройки - [config.md](config.md).

## 6. Провода DOS_N и /WAIT

Beta Disk платы (`DISKSYS=TRDOS`) и диски по Wi-Fi работают только при
двух сигналах платы на шине машины:

| Вывод платы | Сигнал |
|---|---|
| GPIO36 | `DOS_N` - включение ПЗУ TR-DOS, выход, активен нулём |
| GPIO34 | `/WAIT` шины Z80, открытый сток |

На классической плате PI-CARD этих проводов нет: их нужно припаять,
куда - по схеме платы и машины. На плате с пометкой PICARD MUSICA доработка
уже сделана, паять ничего не нужно.

В 0.50 доступ машины к Wi-Fi отключён ([README](../README.md)), для Beta
Disk провода нужны и сейчас.

## 7. Что будет без банка

Плата работает. Молчит только MIDI, и по-разному:

| Что | Без банка во флеше |
|---|---|
| IT, XM, S3M, MOD, VGM | играют |
| General Sound | работает, кроме `.mid` |
| DivMMC, Z-Controller, Beta Disk, USB | работают |
| живой MIDI с порта AY | **недоступен всегда** |
| `.mid` через General Sound | **недоступен всегда** |
| `.mid` файлом с плеера | играет, если на карте лежит `midi.ssb`; иначе нет |

Живой MIDI тянет инструменты только из флеша, и банк на карте ему не
замена: поток идёт в реальном времени, ждать карту на каждой ноте некогда.
`.mid`, присланный плеером General Sound, звучит тем же путём, что и живой
MIDI.

В журнале это видно сразу. При включении:

```
boot: no bank in flash (...)
```

а если банка нет и на карте - ещё и

```
boot: no bank (...) - .mid unavailable, the rest works
```

Дальше в каждом разборе состояния повторяется

```
WARNING: no bank - .mid does not play, flash bank.uf2
```

а если банк на карте есть, но живой MIDI или General Sound включены -

```
WARNING: no bank in flash - live MIDI and .mid via GS unavailable, flash bank.uf2
```

При первой же попытке живого потока - один раз

```
live: no bank in flash, live MIDI unavailable
```

## 8. Проверить

При старте плата пишет в журнал, что нашла: настройки, карту, банк
инструментов. Журнал плата только отдаёт: **GPIO 32, UART 115200 8N1**.
Нужен обычный переходник USB-UART, к плате подключаются его вход RX и
земля.

На Спектруме видно имя платы - `PI-MUSICA V` и номер версии, например
`PI-MUSICA V0.50`. Плеер TR-DOS показывает его в строке сведений, в пункте
`BOARD TYPE`; плагин Wild Commander - в строке `Board`. Мусор в имени
означает неполадки на шине.

Если вместо имени написано `NO BOARD` (в плагине `not found`), плата не
отвечает: проверить питание и посадку в разъёме.

## 9. Настроить

Из коробки плата играет музыку по шине, эмулирует General Sound и слушает
живой MIDI. Остального по умолчанию нет: ни DivMMC, ни Z-Controller, ни
Beta Disk, ни эмуляции AY и прочих звуковых устройств, ни клавиатуры USB -
на машине со своими они столкнулись бы на шине.

Включается всё это настройками: с экрана Спектрума или файлом на карте.
Как - [config.md](config.md). Там же готовые файлы под три машины из
каталога `example` в релизе.
