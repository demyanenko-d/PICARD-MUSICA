# Установка

## 1. Выбрать образ

В релизе три образа: две прошивки и банк инструментов отдельно.

Прошивки различаются одним — эмулятором Z-Controller:

| Образ | Z-Controller | Когда брать |
|---|---|---|
| `soundsinth_zcontroller.uf2` | есть | в машине нет своего интерфейса SD-карты |
| `soundsinth_plain.uf2` | нет | интерфейс карты уже есть |

Z-Controller отвечает на портах `0x57`/`0x77`. Если на них отвечает ещё
кто-то, получится конфликт на шине: два устройства на одном чтении. В таком
случае нужен `plain`.

Прошивка весит около полумегабайта и пишется быстро.

| Образ | Размер | Когда нужен |
|---|---|---|
| `bank.uf2` | ~30 МБ | один раз при первой установке |
| прошивка | ~0.6 МБ | при каждом обновлении |

Банк лежит во флеше выше первого мегабайта, а прошивка туда не достаёт:
заливка прошивки банк не трогает. Поэтому обновление — это один короткий
файл, а тридцать мегабайт пишутся только когда меняется сам банк.

## 2. Что заливать

**Обновление** — только прошивка, один файл. Банк остаётся на месте.

**Первая установка** — два файла, по очереди:

1. прошивка (`soundsinth_zcontroller.uf2` или `soundsinth_plain.uf2`);
2. затем `bank.uf2`.

Каждый файл заливается отдельно: после первого плата перезагружается
сама, и для второго её надо снова ввести в режим загрузки.

Банк можно залить и позже. Без него не работает только **живой MIDI**:
он тянет сэмплы прямо из флеша. Файлы `.mid` играют и без него, если на
карте лежит банк — `midi.ssb` в её корне.

## 3. Залить на плату

**Кнопкой BOOTSEL** — если под рукой нет программатора:

1. Отключить питание платы.
2. Зажать BOOTSEL и подать питание.
3. Плата появится съёмным диском — скопировать на него `.uf2`.
4. Плата перезагрузится сама.

Для второго файла повторить с первого шага.

**По SWD** — если программатор есть, это быстрее и без манипуляций с
кнопкой и питанием. Тем, кто собирает из исходников, годятся готовые
скрипты:

```
scripts\flash_zc.cmd            собрать и залить образ с Z-Controller
scripts\flash_plain.cmd         то же без него
scripts\flash_bank.cmd          залить банк инструментов
scripts\flash_zc.cmd bootsel    через BOOTSEL вместо программатора
```

## 4. Звук

Настраивать нечего: прошивка отдаёт 44100 Гц стерео по I2S на ЦАП платы —
GPIO 44 данные, 45 BCK, 46 WS. Куда идёт сигнал дальше, решает сама плата,
а не прошивка; разъём ищите в её собственном описании.

## 5. Перемычка

Перемычка включает и выключает **DivMMC** — эмуляцию ПЗУ и SD-карты,
благодаря которой Спектрум грузится с карты прямо на плате. Ей же
запускается `UNIMOD.sna`.

| Перемычка | Что получается |
|---|---|
| стоит | DivMMC работает, машина может грузиться с карты платы |
| снята | плата в память машины не вмешивается, остаётся звук |

Положение читается один раз при включении питания: на ходу режим не
меняется. Синтезатор, Z-Controller и эмуляция General Sound работают в
обоих положениях.

Подробности — [divmmc.md](divmmc.md).

## 6. Что будет без банка

Плата работает. Молчит только MIDI, и по-разному:

| Что | Без банка во флеше |
|---|---|
| IT, XM, S3M, MOD | играют |
| General Sound | работает |
| DivMMC, Z-Controller, клавиатура и мышь | работают |
| живой MIDI с порта AY | **недоступен всегда** |
| `.mid` файлом | играет, если на карте лежит `midi.ssb`; иначе нет |

Живой MIDI тянет инструменты только из флеша, и банк на карте ему не
замена: поток идёт в реальном времени, ждать карту на каждой ноте нечем.

В журнале это видно сразу. При включении:

```
boot: банка во флеше нет (...)
```

а если банка нет и на карте — ещё и

```
boot: банка нет (...) - .mid недоступен, остальное работает
```

Дальше в каждом разборе состояния повторяется

```
ВНИМАНИЕ: банка во флеше нет - MIDI не играет, залить bank.uf2
```

а при первой же попытке живого потока — один раз

```
live: банка во флеше нет, живой MIDI недоступен
```

## 7. Проверить

При старте плата пишет в журнал, что нашла: режим перемычки, карту, банк
инструментов. Журнал идёт в UART: **GPIO 32 — передача, 33 — приём,
115200 8N1**; нужен обычный переходник USB-UART.

На Спектруме в строке **Board** появляется имя платы —
`PI-MUSICA` с версией. Мусор в нём означает неполадки на шине.

Если имя не появилось, плата не отвечает: проверить питание и
посадку в разъёме.
