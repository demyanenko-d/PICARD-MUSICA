# Банки

MIDI играет не самим `.sf2`, а банком `.ssb` — тем же материалом,
конвертированным на ПК в готовые трекерные инструменты. На плате банк
только читается: ни разбора RIFF, ни перекодирования, ни поиска.

## Откуда взять исходники

Сами `.sf2` в репозиторий не входят: они велики и принадлежат не нам.
В `SF2/` лежат только лицензии. Скачать и положить туда — вручную, **с
точно такими именами**, иначе пекарь исходник не найдёт:

| Файл в `SF2/` | Банк | Где взять |
|---|---|---|
| `GeneralUser-GS.sf2` | GeneralUser GS | [mrbumpy409/GeneralUser-GS](https://github.com/mrbumpy409/GeneralUser-GS) — репозиторий самого автора, S. Christian Collins |
| `SGM-V2.01.sf2` | SGM-V2.01 | [open-soundfonts/SGM_V2_01_soundfonts](https://github.com/open-soundfonts/SGM_V2_01_soundfonts) — лежит тремя архивами, их надо собрать обратно в один `.sf2` |
| `Timbres of Heaven (XGM) 4.00(G).sf2` | Timbres of Heaven 4.00 | [архив на archive.org](https://archive.org/details/timbres-of-heaven-xgm-4.00-g.-7z) (7z, 285 МБ); страница автора Don Allen — [midkar.com](https://midkar.com/SoundFonts/index.html) |

Имена именно эти — они записаны в `scripts/tools/bake_banks.js`. Скобки и
пробелы в имени Timbres входят в него: так файл называется у автора.
Скачанное надо распаковать: SGM разложен на части, Timbres лежит в `7z`.

Без исходника пекарь пропускает банк и говорит об этом; сборка при этом не
падает, просто релиз выйдет без соответствующего `.ssb`. Для `.mid` нужен
хотя бы GeneralUser — он вшивается в образ прошивки.

## Конвертация

Препроцессор звуковых банков (пекарь) — `sf2bake` из хостовой
сборки. Он читает `.sf2` и пишет готовый к загрузке `.ssb`:

```
build/pc/tools/Release/sf2bake.exe вход.sf2 выход.ssb --rate-cap 32000
```

Параметры трёх релизных банков заданы кодом в `scripts/tools/bake_banks.js`,
чтобы не теряться между запусками; результат кладётся в `release/banks/`:

```
node scripts/tools/bake_banks.js            все три
node scripts/tools/bake_banks.js sgm        один
node scripts/tools/bake_banks.js sgm --drum-gain-db 9    подмена ключа
```

Выпечка — **отдельный шаг**, `scripts\build.bat` её не делает: банк
меняется несравнимо реже кода. Полная сборка ожидает готовые `.ssb` в
`release/banks/` и, не найдя их, говорит об этом и продолжает без банка.

## Что препроцессор делает с материалом

| Что | Зачем |
|---|---|
| Разворачивает пресеты и зоны в плоские таблицы | на плате нет ни поиска, ни ветвлений |
| Огибающие из таймцентов в миллисекунды | частота тиков задаётся файлом, а не банком |
| `initialFilterFc` из центов в шкалу среза 0..127 | фильтр движка работает в ней |
| Сводит стереопары в моно с сохранением панорамы | голос движка монофонический |
| Понижает частоту дискретизации до заданного предела | шаг интерполяции ниже единицы — самый дешёвый способ поднять полифонию |
| Кодирует в Dpcm8 или Raw8, расставляет контрольные точки | резидентный формат, байт на отсчёт |
| Нормирует тихие сэмплы к полной шкале, компенсируя громкостью | при восьми битах важна каждая ступень квантования |
| Декодирует результат обратно и считает отношение сигнал-шум | выявляет ошибки кодирования до записи на плату |

Ослабление в банк не записывается: сэмпл, ослабленный на −12 дБ, займёт
шестьдесят кодов из двухсот пятидесяти шести, и громкостью при
воспроизведении разрядность уже не вернуть. Ослабление делается в
32-битном аккумуляторе.

## Основные параметры

| Параметр | Назначение |
|---|---|
| `--rate-cap` | верхний предел частоты дискретизации; 32000 — рабочее значение |
| `--rate-auto` | подбирать частоту дискретизации каждому сэмплу по спектру |
| `--fuse-stereo` | сводить стереопары в моно; без него банк на треть больше |
| `--bank-gain-db` | общее усиление мелодических программ, дБ |
| `--drum-gain-db` | усиление наборов ударных; баланс ударных и остального — разность этих двух |
| `--gm-only` | оставить только 128 программ GM и один набор ударных |
| `--report` | отчёт по каждому сэмплу: частота дискретизации, кодек, отношение сигнал-шум |

Полный список параметров — `sf2bake --help`.

## Размещение банка

**Во флеш-память**, отдельной областью со смещения 1 МБ: прошивка
размещается ниже, банку достаётся почти всё остальное из шестнадцати
мегабайт. При старте прошивка проверяет `crc32` и выводит в журнал, какой
банк найден.

Область отдельная, а не внутри `.uf2`: банк меняется редко, и
обычная запись прошивки по SWD его не затрагивает. В релизный `.uf2` банк
всё же включён — чтобы установка сводилась к одному файлу.

```
scripts\flash_bank.cmd    записать банк по SWD
```

**На SD-карту** — для банков, не помещающихся во флеш-память. Плата
читает их оттуда, встроенный остаётся резервным.

## Свой банк: по шагам

Любой `.sf2` можно превратить в банк платы — релизными тремя дело не
ограничено.

**1. Положить исходник.** Куда угодно, но удобнее в `SF2/`: там он
попадёт под то же правило `.gitignore` и не уедет в репозиторий.

**2. Испечь.** Начать стоит с того же, с чего сделан GeneralUser:

```
build\pc\tools\Release\sf2bake.exe SF2\мой.sf2 release\banks\moy.ssb ^
    --rate-cap 32000 --fuse-stereo --report out\moy.txt
```

`--report` пишет строку на каждый сэмпл: частоту, кодек и отношение
сигнал-шум после кодирования. По нему и видно, что вышло плохо.

**3. Посмотреть, что получилось.** Пекарь печатает сводку: сколько
инструментов, сэмплов и мегабайт, сколько зон понижено по частоте, какая
средняя частота назначена. Решает **размер**. До 15 МБ банк
влезает во флеш-память платы; больше — только на карту.

**4. Послушать.** Банк подставляется ПК-плееру, плата для этого не нужна:

```
build\pc\app\Release\pc_player.exe --play-file трек.mid --bank release\banks\moy.ssb
```

Тем же способом сравниваются два банка на одном файле: `--render-wav` даёт
WAV, и разницу можно смотреть, а не только слушать.

**5. Поставить на плату.** Банк до 15 МБ вшивается в образ или пишется во
флеш-память отдельно (`scripts\flash_bank.cmd`); большой копируется на
SD-карту в корень под именем `midi.ssb`.

**6. Занести рецепт.** Если банк прижился, ключи стоит дописать в
`scripts/tools/bake_banks.js` рядом с тремя релизными — руками их потом не
вспомнить. Именно для этого файл и заведён.

## Все ключи конвертора

`sf2bake <вход.sf2> <выход.ssb> [ключи]`. Встроенная подсказка по `--help`
короткая; полный перечень — здесь.

### Частота дискретизации

| Ключ | Что делает |
|---|---|
| `--rate-cap N` | верхний потолок частоты, Гц. Рабочее значение 32000 |
| `--rate-keep-db X` | не применять потолок к сэмплу, если энергии выше него больше X дБ. По умолчанию −40 |
| `--rate-cap-low N` | нижний потолок для сэмплов, которые от него ничего не теряют. По умолчанию 22050, ноль выключает посэмпльный выбор |
| `--rate-auto` | подбирать частоту каждому сэмплу по его спектру |
| `--rate-auto-min N` | ниже этой частоты не опускать ни при каком спектре. По умолчанию 11025 |
| `--rate-auto-margin X` | частота = граница спектра, умноженная на X. По умолчанию 2.2 |
| `--rate-loss-db X` | порог потери, при котором прореживание считается допустимым |
| `--rate-tilt-db X` | наклон спектра перед сравнением с порогом, дБ на октаву |

### Кодек и разрядность

| Ключ | Что делает |
|---|---|
| `--codec tans\|raw8` | чем кодировать PCM |
| `--force-raw8` | не пробовать Dpcm8 |
| `--q-comp X` | шкала компенсации громкости, дБ на сантибел. По умолчанию 0.1, как в спецификации |
| `--atten-db-per-cb X` | шкала `initialAttenuation`: 0.04 как во FluidSynth или 0.1 по спецификации |

### Стерео, зоны, слои

| Ключ | Что делает |
|---|---|
| `--fuse-stereo` | сводить стереопары в моно; без него банк на треть больше |
| `--fuse-min-corr X` | ниже этой корреляции половин не складывать, а брать громкую. По умолчанию 0.2 |
| `--merge-zones N` | склеивать соседние зоны мультисэмпла, до N в одну |
| `--merge-max-stretch N` | насколько далеко нота может уехать от своей записи, полутонов. По умолчанию 12 |
| `--merge-bright-db X` | порог разницы яркости, выше которого зоны не склеивать |
| `--no-merge-level` | не выравнивать уровень при склейке |
| `--keep-dup-layers` | не выбрасывать одинаковые слои |
| `--even-zones-db X` | сглаживать шаг громкости между соседними зонами. 0 — выключено |

### Петли

| Ключ | Что делает |
|---|---|
| `--loop-xfade N` | кроссфейд на стыке петли, отсчётов |
| `--loop-seam N` | выравнивание точек петли, отсчётов |

### Громкость и состав

| Ключ | Что делает |
|---|---|
| `--bank-gain-db X` | общее усиление мелодических программ |
| `--drum-gain-db X` | усиление наборов ударных; баланс с остальным — разность этих двух |
| `--release 30=2` или `--release 2` | заменить время спада: одной программе или всем |
| `--decay 35=1.2,48=2` | время спада до тишины, секунд, по программам |
| `--gm-only` | оставить 128 программ GM и один набор ударных |
| `--report файл` | отчёт по каждому сэмплу: частота, кодек, отношение сигнал-шум |
